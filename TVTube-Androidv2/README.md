# TV Tube для Android TV

Приложение открывает твой сайт TV Tube на весь экран ТВ. Пульт работает как в браузере: стрелки, OK, «Назад», медиа-клавиши.
Адрес сервера приложение находит само в домашней сети, вводить его не нужно.

## Как получить APK (Android Studio не нужна)
1. Создай бесплатный аккаунт на github.com и новый репозиторий (Private подойдёт).
2. Загрузи в него все файлы из этой папки (Add file → Upload files). Папка `.github` тоже должна загрузиться.
3. Открой вкладку **Actions** → **Build APK** → **Run workflow**. Через 3-5 минут внизу страницы запуска появится файл **TVTube-apk**.
4. Скачай его и распакуй: внутри `app-debug.apk`.

Если у тебя есть Android Studio: открой папку как проект и нажми Build → Build APK.

## Как поставить на ТВ
- **Через флешку:** скопируй `app-debug.apk` на флешку, вставь в ТВ, открой файловый менеджер и установи (разреши «Установку из неизвестных источников»).
- **Через приложение Downloader:** загрузи APK на любой файлообменник, в Downloader на ТВ введи ссылку и установи.
- **Через ПК по сети:** включи на ТВ «Отладку по USB/сети», затем `adb connect IP_ТВ` и `adb install app-debug.apk`.

## Использование
1. На ПК запусти `HOME.bat` (из основной папки TV Tube) и не закрывай окно.
2. На ТВ открой приложение TV Tube. Оно найдёт ПК само за несколько секунд и запомнит адрес.
3. Если адрес ПК поменялся, приложение найдёт сервер заново. Вручную: Настройки → «Сменить сервер».
4. «Назад» закрывает плеер и разделы, на главной нужно нажать «Назад» дважды, чтобы выйти.

Работает на Android TV, Google TV, приставках на Android и телефонах/планшетах с Android 5.0 и новее.
Для Samsung (Tizen), LG (webOS) и Apple TV этот APK не подходит: там сайт открывается через встроенный браузер по адресу из окна сервера.
